# 一、題目說明

## 任務一　在你自己的電腦上做出一個 skill

### 要交出什麼

你電腦上一個真實存在的資料夾，裡面兩個檔案：

```
<你選的 skill 名稱>/
├── SKILL.md              ← 檔名不可以改
└── references/           ← 資料夾名稱不可以改
    └── <一份 .md>
```

建好之後把檔案總管的畫面截圖，貼進作答本第 2 題。
任務二會把這個資料夾搬到 Colab 上去測。

### 主題三選一，選定之後不換

任務二會用一組固定的問句去測你的 skill 會不會被選中，那些問句問的就是
你選的那個主題。換了主題，那些問句就對不上你那一份了。

### 這份 skill 你要自己寫的只有 1–2 條

`SKILL.md` 除了「執行原則」的第 3、4 行，**其餘整份照操作說明貼上**，
`references/` 那一份也是整份貼上。

| 位置 | 誰寫 |
|---|---|
| `name`、`description` | 照抄 |
| `## 何時載入 references` | 照抄 |
| `## 執行原則` 第 1、2 條 | 照抄 |
| **`## 執行原則` 第 3 條** | **你自己寫**（必填）|
| **`## 執行原則` 第 4 條** | **你自己寫**（選填，不寫就把整行刪掉）|

| `## 完成條件` | 照抄 |
| `references/` 那一份 | 照抄 |

### 你交出來的 skill 要符合這幾條

```
[ ] 剛好 2 個檔案：SKILL.md ＋ references/ 底下 1 份。不可以更多
[ ] SKILL.md 裡剛好 4 個 ## 區塊，標題與順序照操作說明那一份
[ ] 「何時載入 references」底下那一句要指名 references/ 裡的檔名（照抄就有）
[ ] 執行原則共 3 或 4 條（照抄 2 條 ＋ 你自己寫 1 或 2 條）
[ ] 你自己寫的每一條 40 字以內
[ ] 整份 SKILL.md 40 行以內
[ ] references/ 那一份 20 行以內
```

notebook 的第 3 格會把這幾項逐條印出來告訴你有沒有過。沒過就回來改，改到過了再往下做。

> 第 3 格還會多印一條「SKILL.md 的 token 數」。**那一條是告知，不是規定**——
> 照上面的結構做就不可能超過，列出來只是讓你看到自己這份有多大，第 4 題會用到。

這份作業量的是「用到才載入」省下多少。一份寫到幾千字的 SKILL.md 會讓
作答本第 4 題的對照算不出東西來。

## 三個情境，挑一個

**挑定之後就不要換。** 任務二會用一組固定的問句去測你的 skill 會不會被
選中，那些問句問的就是你選的那個主題；換了主題，問句就對不上了。

| 代號 | 主題 | skill 名稱（＝資料夾名稱）|
|---|---|---|
| **A** | 簡報大綱生成 | `slide-outline` |
| **B** | 文獻筆記整理 | `lit-note` |
| **C** | 報告格式檢查 | `format-check` |


### 情境 A　簡報大綱生成

它要做的事：使用者給它一份報告或研究內容，它要回一份簡報大綱。

它的輸出要有：

- 建議做幾頁
- 每一頁的標題與重點
- 分得出兩種長度——5 分鐘的簡報和 20 分鐘的簡報，頁數不一樣

`references/` 那一份放：頁面設計建議（標題怎麼下、圖表怎麼配、每頁字量）（檔名 `page-design.md`）


### 情境 B　文獻筆記整理

它要做的事：使用者給它一篇或幾篇文獻，它要回固定格式的閱讀筆記。

它的輸出要有：

- 每一篇各自成一組
- 每一組固定四欄：研究問題／方法／發現／限制
- 找不到的欄位要寫「未提及」，不可以留空也不可以自己補

`references/` 那一份放：四欄各自要寫到什麼程度、引述原文怎麼標出處（檔名 `note-format.md`）


### 情境 C　報告格式檢查

它要做的事：使用者給它一份報告，它要依 APA 第七版逐項回報哪裡格式不符合。

它的輸出要有：

- 檢查三個面向：引用格式／標題層級／圖表標號
- 每一個不符合的地方都要附「原文怎麼寫」與「該怎麼改」
- 規範沒有涵蓋的項目要說無從判定，不可以自己補一條規則

`references/` 那一份放：APA 第七版三種常見條目格式，與最常見的三個錯誤（檔名 `apa-basics.md`）

# 二、操作指引

## 怎麼建

**可以複製貼上，不必逐字打。** 重點是資料夾與檔案是你自己建出來的。

### 步驟 1　建資料夾

在任何你找得到的地方（例如桌面）建一個資料夾，名稱用你選的情境的 skill 名稱。

### 步驟 2　在它裡面再建一個資料夾，命名 `references`

建好之後結構是這樣：

```
<skill 名稱>/
├── SKILL.md
└── references/
    └── <一份 .md>
```

### 步驟 3　建 `SKILL.md`

用**純文字編輯器**開新檔，把下面的內容貼進去，存成 `SKILL.md`，
放在最外層那個資料夾底下。

> 純文字編輯器就是不會偷偷加格式的那種。Windows 的「記事本」、
> macOS 的「文字編輯」、VS Code 都算。**不要用 Word**——
> 它存出來的不是純文字。

⚠ 檔名必須剛好是 `SKILL.md`——**`SKILL` 全大寫、`.md` 全小寫**。
寫成 `skill.md` 或 `Skill.md` 會認不出來。

⚠ **存檔時要確認副檔名沒有被改掉。**
用記事本的話，「存檔類型」要選「**所有檔案**」，否則會存成 `SKILL.md.txt`；
用 macOS 的「文字編輯」要先在「格式」選「**製作純文字**」。

```markdown
description: 把報告或研究內容整理成簡報大綱，支援不同長度的簡報（例如 5 分鐘或 20 分鐘），列出建議頁數與每頁重點。當使用者要把內容整理成簡報大綱或安排投影片架構時使用。

## 何時載入 references

3. 【換成你自己寫的一條，40 字以內】
4. 【這一行選填；不寫就整行刪掉】

## 邊界條件

- 使用者沒有說明簡報長度時，不得自行假設，要先詢問

## 完成條件

- [ ] 已列出每一頁的標題與重點
- [ ] 頁數落在建議範圍內（或已說明為什麼不在範圍內）
```

資料夾裡**，檔名照下面標示的那一個。

#### 情境 A（簡報大綱生成）　存成 `references/page-design.md`

```markdown
# 頁面設計建議

## 標題寫法

標題直接寫結論，不要只寫主題詞（例：「延遲降低 40%」比「效能改善」好）。

## 圖表配置

- 每頁最多一張圖或一個表，避免視覺過載
- 圖表要附一句話講「這張圖在說什麼」，不要讓讀者自己猜

## 每頁的字量

- 條列最多四項，每一項不超過兩行
- 整段文字不放進投影片，要講的話寫在備忘稿裡
```

#### 情境 B（文獻筆記整理）　存成 `references/note-format.md`

```markdown
# 四欄筆記的填寫細則

- **研究問題**：抓作者自己說「本研究要回答什麼」的那一句，不要用摘要第一句代替
- **方法**：資料來源與分析方式兩件事都要寫，例如「訪談 12 位教師，主題分析」
- **發現**：只寫作者主張有證據支持的結果；作者自己標為推測的不算
- **限制**：優先抄作者自己承認的限制。作者沒寫時才由讀者判斷，並註明「讀者判斷」

## 引述原文時

標出處到節名或頁數，例如（第 4.2 節）或（p. 118）。整段照抄要加引號。
```

#### 情境 C（報告格式檢查）　存成 `references/apa-basics.md`

```markdown
# APA 第七版　三種常見條目格式

- **期刊論文**：作者, A. A. (年). 文章標題. *期刊名, 卷*(期), 起頁–迄頁. https://doi.org/xxxx
- **專書**：作者, A. A. (年). *書名* (版次). 出版社.
- **網頁**：作者或機構. (年, 月 日). *標題*. 網站名. 取自網址

## 最常見的三個錯誤

- 期刊名與卷號要斜體，期號不斜體
- 兩位作者之間用 `&`，不是 `and`
- 標題層級最多到第五級，第一級置中粗體、第二級靠左粗體
```

## 卡住的話

| 症狀 | 原因 | 怎麼處理 |
|---|---|---|
| 檔名變成 `SKILL.md.txt` | Windows 記事本預設加 `.txt` | 存檔類型改「所有檔案」；或在檔案總管開啟副檔名顯示後改名。macOS 用「格式 → 製作純文字」 |

| notebook 第 3 格說佔位行還在 | 步驟 5 漏做，或方括號沒刪掉 | 連 `【` `】` 一起換掉 |
