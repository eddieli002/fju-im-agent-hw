## ① 成品長什麼樣

這一份的主題是**查詢課程作業的死線**。`course-deadline` 這個 skill 做的事是：
使用者問作業什麼時候交，它依週次對照表回答截止日與繳交方式。

> **注意**：這個主題與你要做的三個情境（A 簡報大綱／B 文獻筆記／C 報告格式檢查）
> **都不一樣**。這一頁給你看的是「結構」，不是可以照抄的內容。

資料夾長這樣——就這兩個檔，不多不少：

```
course-deadline/
├── SKILL.md
└── references/
    └── schedule.md
```

| | |
|---|---|
| 資料夾名稱 | `course-deadline`——必須與 `SKILL.md` 裡的 `name` 完全相同 |
| `SKILL.md` | `SKILL` 五個字母**全大寫**，`.md` 全小寫 |
| `references/` | 資料夾名稱全小寫，底下放 1 個 `.md` |
| 全部行數 | `SKILL.md` 27 行（上限 40）、`schedule.md` 12 行（上限 20）|

## ② 兩個檔案的全文

### `SKILL.md`

四個 `##` 區塊的順序是固定的：`## 何時載入 references`、`## 執行原則`、`## 邊界條件`、`## 完成條件`。
`---` 包起來的那一段就是 **frontmatter**，它之後的全部內容是 **body**。

```markdown
---
name: course-deadline
description: 回答這門課的作業繳交時間與當週要交什麼，依週次對照表查出對應的作業名稱、截止日與繳交方式。當使用者問作業什麼時候交、下週要交什麼或某一份作業的死線時使用。
---

# Course Deadline

## 何時載入 references

- 任何涉及具體日期或週次的問題，都要先讀取 `references/schedule.md`，不得憑記憶回答
- 只問繳交方式這類不涉及日期的問題，依下方原則回答即可

## 執行原則

1. 先確認使用者問的是哪一份作業或哪一週，問法含糊時先反問
2. 回答一律附上該作業的截止日與繳交方式兩項
3. 同一週有多份作業時全部列出，依截止日先後排序
4. 日期寫成完整格式（例：11/18（二）23:59），不使用「下週」這種相對說法

## 邊界條件

- 對照表沒有收錄的作業，說明查不到，不得推測日期

## 完成條件

- [ ] 回答裡出現具體日期
- [ ] 已說明繳交方式
```
